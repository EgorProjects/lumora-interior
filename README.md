# Lumora Interior

Премиальный одностраничный сайт для студии дизайна интерьеров.
Учебный проект: чистый frontend на **HTML5 + CSS3 + Vanilla JavaScript**, без фреймворков и сборщиков.

**🔗 [Живое демо](https://egorprojects.github.io/lumora-interior/)** · **📦 [Репозиторий](https://github.com/EgorProjects/lumora-interior)**

---

## Как запускать

Проект использует ES-модули (`type="module"`), поэтому файл нельзя просто открыть через `file://` — нужен локальный сервер.

**Вариант 1 — VS Code:** расширение **Live Server** → правый клик по `index.html` → *Open with Live Server*.

**Вариант 2 — Python:**

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

**Вариант 3 — Node.js:**

```bash
npx serve .
```

## Секции сайта

1. **Header** — фиксированная навигация, активный якорь, бургер-меню на мобильных.
2. **Hero** — первый экран: крупный заголовок, описание, CTA, большое фото.
3. **About** — философия студии, преимущества и строка статистики.
4. **Services** — четыре карточки услуг с hover-эффектом.
5. **Portfolio** — четыре карточки проектов (фото, тип, площадь).
6. **Testimonials** — три отзыва клиентов.
7. **Contact** — форма обратной связи + футер.

## Важные ограничения (честно о проекте)

### Форма работает только на клиенте

Backend в проекте **отсутствует**. Настоящей отправки заявки на сервер нет:
при сабмите данные проверяются в браузере, показывается демонстрационное
сообщение об успехе, и всё. Чтобы заявки реально приходили, нужно подключить
сервис форм (Formspree, Netlify Forms) или собственный API — это отдельный этап.

### Изображения

Фотографии на сайте — с [Pexels](https://www.pexels.com/license/) (бесплатная
лицензия, свободное коммерческое использование). Лежат в `assets/img/`
(6 файлов: hero, about, 4 проекта). Референс-скриншоты из корня проекта
**не используются как контент сайта** — они служили только для вдохновения
при разработке дизайна.

Названия проектов и отзывы клиентов **вымышлены** —
это учебный пример. Пометки об этом размещены прямо на странице
(в секциях Portfolio и Testimonials).

### Нет реальных контактов

Телефон, email и адрес в футере/контактах — условные.

## Технологии и подходы

- **HTML5**: семантическая разметка (`header`, `main`, `section`, `footer`), `lang="ru"`.
- **CSS3**: CSS-переменные, Grid, Flexbox, `clamp()`, mobile-first медиазапросы, BEM-подобная нотация.
- **JavaScript**: ES-модули, `IntersectionObserver`, валидация форм, делегирование событий, без глобальных переменных.
- **Доступность**: `aria-expanded` / `aria-describedby` / `role="alert"`, видимый фокус `:focus-visible`, поддержка `prefers-reduced-motion`, тач-цели ≥ 44px.
- **Производительность**: `loading="lazy"` у изображений, фиксированные размеры img (защита от CLS), анимации только на `transform`/`opacity`.
